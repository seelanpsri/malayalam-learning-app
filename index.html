📐 மலையாள இலக்கண மாற்றச் சுருக்கம் (Grammar Guide)
1. எழுவாய் மாற்றம் (Pronouns in Dialect)
• நீ (Nee) ➡️ மலப்புரத்தில் இஜ்ஜ் (Ijj)
• நான் (Njaan) ➡️ மலபாரில் அன்பாக நம்மள் / ஞம்மள் (Njammal)
• அவன் / அவள் ➡️ ஓன் (On) / ஓர் (Or)
2. விசேஷணம் & பெயரெச்சம் (Adjectives)
மலையாளத்தில் பெயருக்கு முன்னால் '-உள்ள' (-ulla) சேர்ப்பது வழக்கம்:
• ருசி + உள்ள = ருசியுள்ள (Ruchiyulla) = சுவையான
• சூடு + உள்ள = சூடுள்ள (Choodulla) = சூடான
• பங்கி + உள்ள = பங்கியுள்ள (Bhangiyulla) = அழகான
3. துணைவினைகள் (Modals & Auxiliaries)
• வேண்டும் (-anam) ➡️ போகணம் (Pokanam) / மலப்புரம்: போணம்
• வேண்டாம் (-enda) ➡️ போகேண்டா (Pokenda) / போவண்டா
• முடியும் (Can) ➡️ பற்றும் (Pattum) / மலப்புரம்: ஒக்கும் (Okkum)
• முடியாது (Cannot) ➡️ பற்றில்ல (Pattilla) / ஒக்கில (Okkila)
